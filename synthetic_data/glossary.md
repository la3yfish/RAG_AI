# UnitTech — Glossary (Synthetic)

This document defines key terms used across UnitTech internal documents.
It is intended to be unambiguous and stable for retrieval tests.

## Terms

- **Client**: A legal entity (B2B) purchasing goods/services from UnitTech.
- **Project**: A client engagement tracked under a `proj_###` identifier.
- **Order**: A purchase order within a project; may be split into shipments.
- **Shipment**: A logistics event delivering goods to the client.
- **Invoice**: A billing document issued by UnitTech for delivered goods/services.
- **SLA**: Service-level agreement for response times to client requests.
- **Claim**: A client complaint about quality/quantity/delivery.
- **OCR**: Text extraction from scanned (image-only) documents.
- **ADE**: Agentic Document Extraction — structure-preserving extraction from complex documents (tables, multi-column layouts), producing structured outputs (e.g., Markdown tables or JSON blocks) rather than plain text.

## Naming conventions

- Employee IDs: `emp_###`
- Project IDs: `proj_###`
- Document IDs: `doc_YYYYMMDD_<type>_<seq>`
